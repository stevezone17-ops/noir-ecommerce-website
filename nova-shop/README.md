# NOIR — E-commerce storefront

A responsive demo e-commerce website built with HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser, or open this folder in VS Code and use the Live Server extension.

## Features

- Responsive landing page and product catalog
- Category filters, product search, and price sorting
- Shopping bag with quantity controls and subtotal
- Cart persistence using browser localStorage
- Demo newsletter form

## Important

This is a **frontend demo**, not a production-ready store. Checkout does not process payments; newsletter signups are not submitted. Products are sample data in `script.js`, and product images and fonts require internet access. Before selling, add a backend, database, inventory tracking, authentication as needed, payment gateway, server-side validation, and legal/store policies.
